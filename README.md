# AI 用量、余额与积分小组件 · Codex / Claude / DeepSeek / WorkBuddy

**Codex / Claude 额度、DeepSeek 余额、WorkBuddy 国内个人积分；支持 Parrot、Sub2API 与官方账号，适用于 iPhone 主屏和锁屏**

基于 [Scripting](https://apps.apple.com/app/id6479691128)，显示 Codex / Claude 的 5 小时、每周剩余额度、重置倒计时与可用重置卡。主屏还可显示今日与本月用量统计，支持多账号排序、自定义名称和点击刷新。DeepSeek使用独立余额显示，WorkBuddy使用剩余积分、已用／总量及资源有效期显示，均不套用5小时／每周额度。小组件窗口标签为 `5 h`、`7 d`，剩余天数用 `d` 表示。

## 功能与显示

进入或重新打开 App 只读取本机缓存，不自动联网或续期。App 内不提供单独的“刷新额度”或连接状态模块；新增账号、授权成功、切换来源以及“保存并测试”仍会触发读取，主屏小组件可点击双箭头刷新。

- **账号来源**：OAuth,API、Parrot、Sub2API 三选一。Parrot／Sub2API 自动发现账号与 DeepSeek 频道；官方账号支持 Codex／Claude 授权登录、WorkBuddy 国内个人浏览器登录和 DeepSeek 官方 API Key 直接添加。Parrot可读取WorkBuddy积分快照；官方版Sub2API暂不支持WorkBuddy。
- **统计来源**：Parrot、Sub2API 独立二选一，不合计。可以组合使用，例如官方额度＋Sub2API统计。
- 配置、账号缓存、排序与自定义名称按账号来源隔离；切换不会删除另一来源的配置或登录。
- 重置卡只跟随当前账号来源，不从统计来源或其他服务补齐。有效数量大于 0 时显示 `RE:N`；0 或未知时隐藏。只查询，不兑换重置卡或重置额度。
- 未提供的额度显示 `--`，不填成 0。任一窗口剩余百分比**真实为 0**时，该账号的图标、服务标题、两窗数字、百分比和点亮进度块统一置灰。非零小数、未知值、暂不可用和账号停用状态本身不触发灰显。WorkBuddy只在可靠确认剩余积分为0时灰显，正常状态使用离线内嵌的官方彩色图标。

| 小组件 | 显示内容 |
| --- | --- |
| 主屏小号 | 最多 2 个账号，上下排列；只选 1 个时，顶部显示今日／本月的缓存、缓存率、Token、花费 |
| 主屏中号 | 最多 4 个账号；选 2 个时，上方显示六项统计、下方并排显示账号；选 3 个时，一个格子显示四项统计 |
| 主屏大号 | 顶部显示今日／本月六项统计，下方纵向显示最多 4 个账号 |
| 锁屏矩形 | 只显示所选序列的第一个账号，包含标题及 5 h／7 d 两行额度，DeepSeek 显示余额明细，WorkBuddy显示积分明细 |
| 锁屏圆形／单行 | 只显示第一个账号；圆形显示 5 h 剩余百分比，单行显示两窗百分比（系统支持时）；DeepSeek 显示余额，WorkBuddy显示剩余积分 |

六项统计为输入、输出、缓存、缓存率、Token、花费。锁屏不显示统计或刷新按钮，由系统按锁屏样式着色。

## 安装

1. 安装 Scripting，在 iPhone 上打开以下导入地址：

```text
https://scripting.fun/import_scripts?urls=["https%3A%2F%2Fgithub.com%2FWangsc1%2Fai-usage"]
```

2. 在 Scripting 中运行脚本，选择账号来源并按下方步骤配置。
3. 在主屏或锁屏添加 Scripting 小组件，编辑小组件并选择本脚本。主屏可填写账号参数。

主屏点击刷新需要 iOS 17+ 及支持 AppIntent 的 Scripting。实际授权、交互和布局以设备支持情况为准。

## 配置账号来源

### Parrot

1. “账号来源”选择 **Parrot**。
2. 在“Parrot 连接”填写自己的部署地址和 **`managementKey` 管理密钥**。
3. 点“保存并测试”，确认账号列表与额度读取成功。

DeepSeek频道通过管理接口自动分页发现，无需逐账号填写API Key。读取服务器余额快照，保留其采集时间；较旧部署没有频道接口时原Codex／Claude账号仍可读取。API频道名称改变会改变公开ID，不按凭据猜测迁移排序或别名。

普通 OpenAI API Key 不是 Parrot 管理密钥，不能用于此处。已存密钥显示前4字符，其余以 `*` 遮蔽（不超过4字符全部遮蔽）；点输入框填写新密钥，留空保存沿用原密钥。Parrot 账号列表包含已停用账号，但脚本不会改变远端状态。重置卡仅在服务提供对应字段时显示，否则保持未知。

### 官方账号（Codex / Claude OAuth、DeepSeek、WorkBuddy）

选择 **OAuth,API**，再在“添加账号”右侧选择对应服务。官方登录和额度读取不需要 Parrot 或 Sub2API；今日／本月统计需要另外配置统计来源。可以添加多个 Codex、Claude、WorkBuddy 账号，重复登录同一身份会更新原记录。

#### Codex

1. 点“添加账号”准备浏览器 OAuth + PKCE 登录，再点“点击登录”打开 App 内临时浏览器。
2. 登录目标 ChatGPT 账号。本机收到有效回调并成功保存登录后，自动关闭授权页返回设置列表并刷新；关闭网页本身不代表授权成功，未收到回调时可再次点“点击登录”。
3. 本机等待期限为15分钟（不是 OpenAI 公布的授权有效期）；取消、切换服务／来源或退出设置会结束本次登录。

浏览器回调仅监听 `127.0.0.1:1455/auth/callback`，绑定失败仅尝试1457。缺少能力、端口不可用或加载失败时显示原因，可重试登录。

#### Claude

1. 点“添加账号”，再点“点击登录”，登录目标订阅账号并授权。
2. 本机回调可用时会自动接收结果并在成功保存后自动关闭授权页返回设置列表；不可用时采用手动流程。
3. 手动流程中，将授权页提供的**完整 `code#state`**粘贴到“本次完整授权码”，点“完成Claude授权”。必须匹配当前这次授权的 state，不能使用旧流程或他人的代码。

授权页在 App 内临时浏览器中打开，加载失败时在登录区显示原因并可重试。切换到手动流程会生成新的授权状态，不能复用旧自动流程的代码。授权 15 分钟后失效；取消、退出设置或切换来源／登录服务会结束本次尝试。

Claude 使用官方 OAuth 权限组合，包含资料、订阅推理、Claude Code 会话、连接器和文件上传权限；本脚本只用于登录、读取资料与额度，不执行推理、连接器或上传业务。

#### DeepSeek

账号来源选“OAuth,API”，在“添加账号”同行右侧选择“DeepSeek”，先点“添加账号”，再在“登录账号”顶部输入官方API Key后点“保存”，直接保存并验证余额。新增账号默认名称为“DeepSeek”，固定使用API Key。每次添加独立账号，支持多个账号及局部退出；API Key账号凭据失效可移除该账号后重新添加。

- **API Key**：只请求 `https://api.deepseek.com/user/balance`，显示总余额、充值余额、赠送余额及可用状态。
- **已有网页User Token账号**：保留凭据、原查询能力和局部退出，不再提供新添加入口。不是API Key，也不是OAuth。查询 `platform.deepseek.com/api/v0/users/get_user_summary` 与 `api/v0/usage/by_api_key/cost`，显示账户余额及北京时间包含今天的7个自然日消费。属于私有网页接口，可能变化或拒绝请求；不冒充浏览器，不自动登录或续期，Token失效需手动更新。
- 多币种分别显示，绝不合计CNY／USD；没有币种归属的多币种消费保持未知。余额、消费失败保留原数据和采集时间并显示错误，不显示DeepSeek缓存标记，缺失不当作零。
- **没有已核实可用的DeepSeek订阅查询接口**，不显示虚构套餐、到期或订阅百分比。近7日消费不是Token数，不替代今日／本月全站六列统计。
- 参考 [SylvanRoe/Scripting · DashBoard-Kit](https://github.com/SylvanRoe/Scripting/tree/9eadd3070c9385df8828928ad7eae77316eb8507/DashBoard-Kit) 的endpoint、字段与主余额／次明细思路，独立实现；不自动读取其他脚本或共享目录的密钥，不复制其源代码／素材。

账号列表和小组件共用内嵌品牌图标：Claude 为橙色，OpenAI 随浅深色模式显示黑／白，DeepSeek 使用[官方图形](https://api-docs.deepseek.com/img/logo-mark-light.svg)并着色为蓝色 `#4D6BFE`，无需联网加载图标。

主屏小中大在原账号格位显示账户余额和明细／7日消费及错误，不在余额下方显示采集时刻；主屏组件底栏刷新时间保留。锁屏矩形显示余额明细，圆形／单行显示余额，不绘制额度百分比。多币种或较长金额可能受系统格位限制缩小／截断。

#### WorkBuddy（国内个人）

1. 账号来源选 **OAuth,API**，在“添加账号”右侧选 **WorkBuddy**，点“添加账号”再点“点击登录”。
2. 在独立临时浏览器中登录腾讯WorkBuddy个人身份。服务返回令牌并成功保存本机Keychain后，自动关闭网页返回App并读取真实积分。
3. 本机等待期限为10分钟，不是官方公布的授权有效期。取消、关闭网页、退出设置或切换服务／来源会结束本次尝试；迟到响应不会保存账号。企业身份和国际版不支持。

- 使用已核实开源实现的国内 **CLI** 客户端私有 `state → token → account` 协议，不是公开第三方OAuth或API Key接口。认证固定访问 `copilot.tencent.com`，积分固定访问 `www.codebuddy.cn`；不跟随API重定向、不复制浏览器或其他应用Cookie，仅在同一state流程内保留该接口自身返回的临时Cookie。参考 [Parrot认证实现](https://github.com/danger-dream/Parrot/blob/25b93d344b7cfc81dce0c210cb579ada4d8b48a1/src/oauth/workbuddy/auth.py)。私有接口和客户端profile可能变化或受到风控，不能保证每次登录成功。
- 访问令牌临期或积分接口返回401时，单次读取最多续期一次，并保存轮换令牌。网络失败不等于凭据失效；保存失败可在当前执行内重试保存轮换候选，不重复使用已轮换的旧refresh token。多个系统执行仍可能竞争，不能保证跨进程互斥；失效时重新登录。
- 个人资源包完整分页，优先精确数字，未知／不完整／读取失败不当作零。显示积分而非现金，资源到期与周期结束分别保留，不编造5 h／7 d窗口。
- 主屏小中大及锁屏矩形显示剩余积分、已用／总量、可用资源包最早到期；圆形／单行以剩余积分为主。组件不显示账号采集时间，底栏原有全组件刷新时间保留。在设置页“WorkBuddy个人积分（缓存）”可查看真实采集时间、全部资源明细和两种时间，打开明细不联网。组件空间和锁屏系统样式可能限制文字显示。
- Parrot来源继续只读其管理详情积分快照，不直连腾讯、不触发服务刷新状态、签到或试用。缺少字段或旧版服务不影响其他账号；保留此前可靠积分及真实采集时间并标注读取失败／此前快照。
- 官方彩色[品牌图标](https://assets.workbuddy.cn/web/workbuddy/f4728a12fe9cfe5a34da6b2fa827614041c84386/assets/logo.svg)由原官方SVG直接转换为离线内嵌彩色PNG，以原色图像模式显示，不重画或改变正常品牌色；可靠零积分时灰显，锁屏最终颜色受系统控制。

#### 官方账号管理

- Codex／Claude在App显示完整邮箱；小组件默认显示邮箱前缀，也可设置自定义名称。邮箱未提供时会明确提示。
- 在“登录账号”列表左滑点“删除”，只移除此账号的本机登录及对应显示数据，不退出其他账号，也不是撤销整个官方会话。
- Codex／Claude账号读取与小组件刷新共用续期逻辑：访问令牌临近到期或额度接口返回 401 时尝试续期，并保存服务返回的轮换令牌。网络故障、429 或 5xx 不等于登录失效，保留登录和可用额度缓存；429 按有效 `Retry-After` 冷却，未提供时本机退避 5 分钟，冷却后在下次正常刷新时再尝试，不使用后台定时器或无限重试。续期前及失败后会重读本机凭据；若另一执行已保存有效新令牌，会优先复用。仍明确返回 `invalid_grant` 且没有有效新凭据时提示重新添加账号。多个系统执行同时续期仍可能竞争，不能保证跨进程严格互斥。Claude授权交换与续期都使用JSON协商和脚本自身的诚实HTTP标识，不冒充官方客户端；这些兼容设置不能保证消除429。此机制不能消除官方限流，实际续期仍受服务、权限、网络及系统调度限制。

### Sub2API

[Sub2API](https://github.com/Wei-Shaw/sub2api) 的账号额度与统计共用一份配置。

1. 账号来源或统计来源选择 **Sub2API**，显示“Sub2API连接”。
2. 填写部署**根地址**和 **Admin API Key 管理员密钥**，不是普通用户 API Key。
3. 点“保存并测试”，确认账号列表。统计时区默认 `Asia/Shanghai`，沿用已保存配置，决定今日与自然月的日期边界；设置页不再提供时区输入栏。

- 管理员密钥权限较高，使用可信部署及 HTTPS，不要分享密钥。已存密钥显示前4字符，其余以 `*` 遮蔽（不超过4字符全部遮蔽）；点输入框填写新密钥，留空保存沿用原密钥。
- 官方版Sub2API暂不支持WorkBuddy，不把兼容OpenAI频道识别为WorkBuddy。账号额度支持 Claude OAuth／SetupToken 和 Codex OAuth；自动纳入DeepSeek按量账号，通过管理余额接口读取多币种总余额，无需额外Key。Sub2API接口未提供赠送／充值拆分，显示未提供。余额不冒充 5 h／每周额度；SetupToken 重置卡未知。
- 统计是该部署**全站汇总**，不按用户、Key 或小组件所选账号过滤；花费是实际扣费，不是标准计费或上游账号成本。
- 客户端只发送 GET 查询，不调用兑换、重置或写入刷新接口；额度查询可能由 Sub2API 请求上游服务。
- 改变地址或密钥会清理 Sub2API 对应缓存，避免混用。较旧部署缺少接口时显示错误或未知；单账号读取失败保留列表及该来源可用缓存，不用其他来源替代。

## 配置统计来源

在“统计来源”选择 **Parrot** 或 **Sub2API**，并填写该服务配置。统计选择与账号来源完全独立，默认使用 Parrot。

统计不代表某个官方账号的单独用量，也不按组件参数过滤：

- **缓存**：缓存读＋缓存写；**缓存率**：缓存读÷（输入＋缓存读＋缓存写）。
- **Token**：Parrot 为输入、输出、缓存读和缓存写之和；Sub2API 使用服务返回的总量。
- **花费**：Parrot 为服务提供的估算金额，Sub2API 为实际扣费；显示保留一位小数。

未配置或字段未提供时显示未提供，不填零。统计失败不阻止额度刷新；有对应统计缓存时保留。额度缓存与统计缓存的时效可能不同。

## 账号排序、参数与名称

设置页账号列表以“序号 + 服务图标（Codex 为 OpenAI 图标）+ 邮箱／名称”显示。

### 排序与默认账号

官方来源：在“登录账号”标题右侧点“编辑”，拖动账号行右侧把手，松手即保存，点“完成”恢复左滑删除与点击改名；若当前 Scripting 不提供该编辑能力，则显示“账号排序”入口，进入后长按卡片拖动。Parrot／Sub2API：在“目前账号”→“账号排序”，长按卡片拖动，松手即保存。列表编号随排序变化；新账号追加到末尾。三种账号来源的排序分别保存，包含已停用账号，不会启用或停用远端账号。

不填参数时，主屏小号取前 2 个，中／大号取前 4 个，锁屏取第一个。App 列表本身不限 4 个账号。

### 指定账号参数

长按主屏小组件 → 编辑 → 参数，填写**排序后的序号，从 1 开始**：

| 参数 | 含义 |
| --- | --- |
| `3` | 只显示第 3 个账号；小号同时显示统计区 |
| `3,1` | 依次显示第 3、第 1 个账号 |
| `1，2` 或 `1 2` | 中文逗号、空格也可分隔 |

重复序号只取一次，无效序号忽略，最多选 4 个。参数顺序优先于默认顺序；排序后同一数字可能对应不同账号，请按需调整。在设置页“刷新预览”分组中点“预览组件”，打开 Scripting 原生预览，初始为小号；参数、尺寸、主题和重新加载由原生界面提供，菜单文字及可选尺寸由 Scripting 控制。

### 自定义名称

在“登录账号”（官方来源）或“目前账号”（Parrot／Sub2API）中点账号，填写“小组件用户名”后点“保存”，会重载小组件并自动返回上一页。留空保存恢复默认名，支持 Emoji；仅影响本机小组件，App 账号列表和排序页仍显示原名。

## 刷新与冷却

- 主屏右下双箭头可手动读取当前账号额度和所选统计，并请求重载小组件。失败时沿用可用缓存及原成功时间。
- 在“刷新预览”分组中，“刷新间隔”可选 **5、15、30、60 分钟**，默认 15 分钟。设置会保存，但这是向 iOS 请求刷新，**不是精确后台定时器**；系统可能延后或合并请求。手动刷新不改变间隔。
- Claude 额度读取遇到 429／403 时按服务等待时间冷却；无有效等待时间时默认 5 分钟，最长 1 小时。冷却期间不再请求该账号额度、不自动重试，使用已有缓存。缩短组件间隔或点击刷新不能绕过服务冷却。
- Claude 授权交换遇到 429 会结束本次流程，不自动重试一次性代码。有有效等待时间时显示冷却截止；到期后需发起新授权。没有有效等待时间时提示稍后再试，不编造截止时间。
- 授权与额度冷却截止均显示**北京时间**和剩余秒数。Sub2API 统计默认使用 `Asia/Shanghai`，已有配置沿用原时区。

主屏小组件使用浅色／深色自适应的默认渐变背景，不提供背景切换。锁屏仍由系统按锁屏样式着色。

## 安全与实际限制

- 地址、管理密钥／会话和官方令牌只保存在本机脚本隔离的 Keychain，默认不开启 iCloud 同步；Codex、Claude、WorkBuddy凭据分别保存。排序、名称、额度和统计使用本机缓存，切换来源不会跨源拼接账号或重置卡。授权码、state 与 PKCE 仅用于本次内存流程，不写日志或持久保存。
- Parrot 和 Sub2API 管理密钥具有高权限。不要公开密钥、token、完整授权码或带凭据的备份；HTTP 会明文传输服务凭据，建议 HTTPS。
- 官方账号直接访问相应官方服务：Codex 使用 `auth.openai.com`、`chatgpt.com`；Claude 授权页使用 `claude.com`，令牌与资料／额度使用 `platform.claude.com`、`api.anthropic.com`。WorkBuddy国内个人认证与续期使用 `copilot.tencent.com`，积分使用 `www.codebuddy.cn`，token只发送到这两个固定已核实国内域名。不把官方 token 发给 Parrot、Sub2API 或 GitHub，不复制浏览器 Cookie 或其他应用的登录文件。
- 只读取真实汇总额度，模型专属限额、钱包余额和额外付费金额不充当汇总额度或重置卡。字段缺失、无权限或查询失败保持未知，不凭空填零。
- 本项目是第三方脚本，不是 OpenAI、Anthropic 或腾讯WorkBuddy官方客户端。官方授权、接口版本、风控、组织权限和 Scripting／iOS 兼容性可能变化；当前不支持需要专用路由的 FedRAMP 账号。
- 临时浏览器、Codex／Claude 本机回调、后台刷新、锁屏着色和字体效果均受设备与系统限制，不能保证每次登录成功或刷新准点。
