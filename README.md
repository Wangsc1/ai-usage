# ai-usage

基于 [Scripting](https://apps.apple.com/app/id6479691128) 的 iPhone 桌面小组件，从 Parrot 管理接口读取 AI 用量。

## 显示内容

深色、数码管数字风格，显示订阅账号的**剩余额度**（5 h与每周），账号按最紧张的剩余额度从低到高排序。

| 尺寸 | 内容 |
| --- | --- |
| 小 | 最紧张的 1 个账号：5 h、每周剩余百分比，分段进度条，重置倒计时 |
| 中 | 四宫格，最多 4 个账号；每格 5 h在上、每周在下 |
| 大 | 标题 + 四宫格，最多 4 个账号；每格 5 h在上、每周在下 |

- 数据来源：`/api/management/v1/oauth/accounts`（只显示已启用的账号）
- 剩余额度 > 40% 绿色，15%–40% 橙色，≤ 15% 红色
- 每 15 分钟请求刷新一次（实际刷新时间由 iOS 决定）；请求失败时显示上次缓存，右上角显示断网图标

## 安装

在 iPhone 上点击下面的链接，一键导入 Scripting：

```
https://scripting.fun/import_scripts?urls=["https%3A%2F%2Fgithub.com%2FWangsc1%2Fai-usage"]
```

导入后：

1. 运行脚本，在打开的设置页填写：
   - Parrot 地址，例如 `https://pr.jjbb.me`
   - 管理密钥（Parrot 配置里的 `managementKey`）
2. 点“保存并测试”，显示“✅ 连接成功”后，在桌面添加 Scripting 小组件，长按 → 编辑小组件 → 选择该脚本。

设置页还可以预览三种尺寸、测试连接、清除配置。

## 更新

运行脚本 → 设置页“更新”区域 → 点“检查更新”。会从本仓库拉取最新的 `api.ts`、`widget.tsx`、`index.tsx` 覆盖当前脚本，地址和密钥保留，不需要删除重装。更新后点“完成”退出再重新运行即可生效。

## 安全说明

- 地址、管理密钥和会话凭据都只保存在本机 Keychain（按脚本隔离，不开启 iCloud 同步）。
- 管理密钥只用来换取会话凭据；会话失效后自动重新登录。Parrot 对登录有频率限制（默认每个来源每分钟 5 次）。
- 管理密钥拥有 Parrot 的完整管理权限，请不要把填好密钥的脚本分享给别人。
