# ai-usage

基于 [Scripting](https://apps.apple.com/app/id6479691128) 的 iPhone 桌面小组件，从 Parrot 管理接口读取 AI 用量。

## 显示内容

| 尺寸 | 内容 |
| --- | --- |
| 小 | 今日花费 / Token / 请求数、本月花费，以及第一个账号的 5 小时剩余额度 |
| 中 | 左侧：今日、本月花费与 Token；右侧：最多 3 个账号的 5 小时剩余额度 |
| 大 | 今日、本月按 Claude / GPT 分类的花费，今日 Token 明细（输入 / 输出 / 缓存读 / 缓存写），以及最多 4 个账号的 5 小时、7 天剩余额度和重置倒计时 |

- 数据来源：`/api/management/v1/stats/summary`（today / month）和 `/oauth/accounts`（订阅账号额度窗口）
- 花费为 Parrot 按模型价格**估算**的金额（美元），不是官方账单
- Token 总量 = 输入 + 输出 + 缓存读 + 缓存写
- 只显示已启用的 OAuth 账号，Claude 排在前面
- 每 15 分钟请求刷新一次（实际刷新时间由 iOS 决定）；请求失败时显示上次缓存的数据，并在右上角标出“离线”

## 安装

1. 在 Scripting 中新建脚本项目（例如命名为 `AI 用量`）。
2. 把 `api.ts`、`widget.tsx`、`index.tsx` 三个文件放进项目。
3. 运行脚本，在打开的设置页填写：
   - Parrot 地址，例如 `https://pr.jjbb.me`
   - 管理密钥（Parrot 配置里的 `managementKey`）
4. 点“保存并测试”，显示“✅ 连接成功”后，在桌面添加 Scripting 小组件，长按 → 编辑小组件 → 选择该脚本。

设置页还可以预览三种尺寸、测试连接、清除配置。

## 安全说明

- 地址、管理密钥和会话凭据都只保存在本机 Keychain（按脚本隔离，不开启 iCloud 同步）。
- 管理密钥只用来换取会话凭据；会话失效后自动重新登录。Parrot 对登录有频率限制（默认每个来源每分钟 5 次）。
- 管理密钥拥有 Parrot 的完整管理权限，请不要把填好密钥的脚本分享给别人。
